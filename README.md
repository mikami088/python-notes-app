# 📝 Python Notes App

Простое и удобное настольное приложение для создания, редактирования и хранения текстовых заметок, написанное на Python.

## ✨ Основные возможности
* ➕ Быстрое создание и удаление заметок
* 💾 Автоматическое сохранение изменений
* 🔍 Удобный поиск по названию или тексту заметок
* 🎨 Чистый и интуитивно понятный графический интерфейс

## 🛠 Технологии и стек
* **Язык:** Python 3
* **Интерфейс:** Tkinter / PyQt (оставьте нужное)
* **База данных:** SQLite / JSON-файлы (оставьте нужное)

## 🚀 Как запустить проект локально

1. Убедитесь, что у вас установлен [Python](https://python.org).
2. Склонируйте этот репозиторий или скачайте архив с кодом.
3. Откройте терминал в папке проекта и установите зависимости (если они есть):
   ```bash
   pip install -r requirements.txt
   ```
4. Запустите главное приложение:
   ```bash
   python main.py
   ```
