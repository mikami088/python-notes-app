#  Python Notes App

Простое и удобное приложение для создания, редактирования и хранения текстовых заметок, написанное на Python.

 Основные возможности
* Быстрое создание и удаление заметок
* Автоматическое сохранение изменений
* Удобный поиск по названию или тексту заметок
* Чистый и интуитивно понятный графический интерфейс

Технологии и стек
* **Язык:** Python 3
* **Интерфейс:** Tkinter
* **База данных:** SQLite
